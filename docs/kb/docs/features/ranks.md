# Rank Stacks

The Ranks section on the dashboard draws one stack per tracker. Each stack has one segment per class you can earn on that tracker, lit from the bottom up to the class you hold now and ghosted above it. Every stack is the same height, so a tracker with three classes shows three thick segments and one with eleven shows eleven thin ones.

## Reading a stack

- The lit segments are the classes you have passed through. The brightest one, with a glow, is your current class.
- The tracker name and your current class sit under the stack. Click the stack to open the tracker's page.
- Hover the stack, or focus it with the keyboard, to see every class with its requirements, highest first, with your own marked.

A class granted by staff, donation or invitation has no segment of its own. If you hold one, the stack shows fully lit with that class name underneath. A demotion class or an administrative state (Leech, Banned, Validating) shows an empty stack under that name.

If the class your tracker reports is not in the tracker registry at all, the name shows in the warning color and the tooltip says so. That is a gap in the registry rather than a problem with your account. See the contributor guide's [User Classes](../contributing/adding-a-tracker.md#3-user-classes) section for how the ladder is recorded.

## Which trackers appear

Only trackers whose registry entry lists a class ladder get a stack. Trackers without one are simply omitted, and the whole section disappears when none of your active trackers has a ladder.

## Turning it off

Open the dashboard settings and switch off **Show rank stacks**. The section header also collapses like the others, and the collapsed state is remembered per browser.

## Limits

Some trackers have two ways up their ladder, one for uploads and one for seed size, and list them in a single order. The stack follows that order, so it shows your rank position, not whether you met every requirement below it. The tooltip shows the requirements for each rung so you can tell the two paths apart.
